## 这一章已合并

本章原标题是「运行时横切结构综合」。在重组本书结构时，它的内容已经拆分到两处：

- **runtime 的横切结构观察（主路径 / 异步旁路 / 长期上下文边界 / 控制面）** → 合并到 [第 27 章 总体运行时架构图](/claude-code-architecture/27-runtime-architecture-map/)
